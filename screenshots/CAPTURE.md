# Screenshots for the mod page

Save these as PNG in this folder with exactly these names; the README links to them. Crop to the forge panel (and
the Forge Oracle panel when it is open) and leave out the character name and the inventory.

| File | What to show |
|---|---|
| `prediction.png` | The forge with an item selected and the prediction line at the top of the description. |
| `panel.png` | The same with the Forge Oracle panel open (`F8`) and the forecast table. |
| `destroyed.png` | An item whose next attempt is predicted to be destroyed, in red. |

Thunderstore only shows images from absolute URLs. Push this folder to the public repository before building the
package (see `docs/DEVELOPMENT.md`).
